# OCR Provider Standard & Engine Abstraction

## 1. Provider Independence
Arthsavora decouples document capture from any single OCR library or third-party service. All OCR implementations conform to the `BaseOCREngine` abstract contract:

```python
class BaseOCREngine(ABC):
    @abstractmethod
    async def extract_text(self, file_path: str, mime_type: str = "image/png") -> OCRRawResult:
        pass
```

`OCRRawResult` encapsulates:
- `text`: Full raw UTF-8 string extracted from the document.
- `confidence`: Bounded float `[0.0, 1.0]` representing average character/word extraction certainty.
- `provider`: Provider identifier (e.g., `tesseract`, `pypdf_native`, `mock_deterministic`).
- `version`: Version string of the active OCR binary or engine.
- `page_count`: Number of document pages processed.
- `metadata`: Arbitrary diagnostic metrics (e.g., word count, execution duration).

## 2. Supported Engines

### 2.1 Tesseract OCR Engine (`TesseractOCREngine`)
- **Technology**: Google Tesseract OCR v5.x via `pytesseract`.
- **Host Detection**: Autodetects standard Windows binary paths:
  - `C:\Program Files\Tesseract-OCR\tesseract.exe`
  - `C:\Program Files (x86)\Tesseract-OCR\tesseract.exe`
  - `%LOCALAPPDATA%\Tesseract-OCR\tesseract.exe`
- **Execution Model**: Dispatches image processing to a non-blocking `asyncio` thread executor to prevent event-loop latency.
- **Confidence Computation**: Scans word-level confidence entries from `pytesseract.image_to_data`, filters out unindexed tokens (`conf >= 0`), and calculates mean normalized certainty.

### 2.2 Native PDF Text Extractor (`PdfTextExtractor`)
- **Technology**: `pypdf.PdfReader`.
- **Purpose**: High-speed, 100% accurate character extraction for vector digital invoices generated by accounting systems (e.g., Tally, Zoho Books, AWS, Swiggy, Zomato, Razorpay).
- **Default Confidence**: Assigned 0.95 for extracted text without the CPU overhead or artifacts of raster OCR.

### 2.3 Deterministic Mock Engine (`MockDeterministicOCREngine`)
- **Technology**: In-memory template matching for CI/CD test automation.
- **Purpose**: Eliminates external binary dependencies and network flakiness in automated integration and regression suites.
- **Pre-packaged Templates**:
  1. `swiggy`: Food delivery bill with 2.5% CGST/SGST, ₹567.50 total, and 12-digit UPI RRN.
  2. `reliance`: Supermarket cash memo with grocery lines, 5% taxes, and credit card reference.
  3. `fuel`: Petrol pump fuel bill with litres, rate per litre, and BharatPe UPI payment.
  4. `default`: Blue Tokai Cafe coffee invoice with tax invoice headers.

---

## 3. Dynamic Factory Selection
Engines are dynamically resolved at runtime via `get_ocr_engine(provider, mime_type)`:
1. If `ARTHSAVORA_OCR_ENGINE == "mock"` or `provider == "mock"`, instantiate `MockDeterministicOCREngine`.
2. If `mime_type == "application/pdf"` and not forced to raster, instantiate `PdfTextExtractor`.
3. Default: Instantiate `TesseractOCREngine`.
